## Descripción General del Sitio

El proyecto consiste en una aplicación web interactiva que reúne una colección de tres juegos dinámicos: **Dados**, **Trivia** y **Blackjack**. El mismo esta hecho en los lenguajes HTML, CSS y JavaScript

## Declaración de uso de IA 

A lo largo del proyecto se utilizo el modelo de inteligencia artificial GEMINI, para tareas del tipo:
* Sugerencias y ayuda con respecto al CSS: Al momento de pulir el css hubo problemas con el renderizado de cartas del Blackjack, tambien, al momento de crear los botones de "INICIO / TRIVIA / DADOS / BLACKJACK / PUNTAJES / INTEGRANTES"
* Resolver problemas con Github: Tuvimos problemas con la plataforma, al momento de trabajar desde distintos dispositivos sobre un mismo repo y la creacion de un "submodulo" que tuvo que ser eliminado 
* Resolver problemas de sintaxis y vinculacion de los archivos: El juego de DADOS tuvo un problema de vinculacion entre el JS y el HTML para el cual hubo que recurrir a la IA para solucionar
* Estructuracion del trabajo: Se le dio el prompt de recomendar en que orden habia que seguir el proyecto en base a lo que habia que hacer, que era mejor hacer primero y que dejar para lo ultimo.
* Resolver problema con los commits: tuve problemas con mi editor de codigo q no me permitia guardar el proceso q habia hecho hasta ese punto, y tuve q pedirle ayuda a la ia para solucionar ese problema.
